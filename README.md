# Анжела Воропинова — гид по Израилю

Сайт-визитка частного лицензированного гида по Израилю с 10-летним опытом работы
с туристами из-за рубежа и русскоязычными израильтянами.

🔗 **Русская версия:** https://angelavoropin.github.io/guide-angela/
🔗 **Версия на иврите (RTL):** https://angelavoropin.github.io/guide-angela/he/

---

## О проекте

Одностраничный сайт-визитка на чистом HTML/CSS/JavaScript — без сборщиков,
фреймворков и внешних зависимостей. Открывается двойным кликом по `index.html`
и одинаково работает на телефоне, планшете и десктопе.

### Разделы

| Раздел | Содержание |
|---|---|
| Первый экран | Представление, ключевое сообщение, счётчики опыта |
| Обо мне | Биография, подход к работе, языки, форматы групп |
| Экскурсии | 6 авторских маршрутов: Иерусалим, Мёртвое море и Масада, Тель-Авив и Яффо, Галилея и Голаны, гастротур, индивидуальный маршрут |
| Почему я | 4 преимущества работы с частным гидом |
| Отзывы | Цитаты гостей |
| Вопросы | FAQ-аккордеон: языки, цены, сроки бронирования, группы, что взять с собой |
| Контакты | Форма заявки, телефон/WhatsApp, email, Telegram |

### Возможности

- Адаптивная вёрстка (CSS Grid + Flexbox), брейкпоинты 960 px и 720 px
- Мобильное меню-бургер
- Анимация появления секций через `IntersectionObserver`
- Анимированные счётчики статистики
- FAQ-аккордеон на нативном `<details>` — открыт только один пункт
- Форма заявки с клиентской валидацией и отправкой через `mailto:`
- Плавающая кнопка связи, появляющаяся при прокрутке
- SEO-метатеги и Open Graph
- Поддержка `prefers-reduced-motion` для пользователей с чувствительностью к анимации
- Семантическая разметка и ARIA-подписи

## Две языковые версии

Сайт существует на двух языках, между которыми есть переключатель в шапке:

| Версия | Путь | Направление | Шрифты |
|---|---|---|---|
| Русская | `/index.html` | LTR | Cormorant Garamond + Manrope |
| Иврит | `/he/index.html` | RTL | Frank Ruhl Libre + Heebo |

Обе версии используют один `style.css`; версия на иврите дополнительно подключает
`rtl.css`, который зеркалит галочки списков, бейдж лицензии, стрелку аккордеона,
плавающую кнопку и кавычки в отзывах, а также изолирует латиницу и цифры
(`direction: ltr`) внутри RTL-текста — чтобы телефон и email не «разворачивались».

Строки интерфейса в `main.js` (валидация формы, тема письма) переключаются
автоматически по атрибуту `lang` у `<html>`. Связь версий размечена тегами
`<link rel="alternate" hreflang="...">` для поисковых систем.

## Запуск

Клонировать и открыть файл:

```bash
git clone https://github.com/angelavoropin/guide-angela.git
cd guide-angela
start index.html      # Windows
```

Либо поднять локальный сервер (нужно для корректной проверки путей):

```bash
python -m http.server 8000
# затем открыть http://localhost:8000
```

## Публикация на GitHub Pages

1. Settings → Pages
2. Source: `Deploy from a branch`
3. Branch: `main`, папка `/ (root)` → Save
4. Через 1–2 минуты сайт доступен по адресу `https://<username>.github.io/guide-angela/`
